## 2. 비즈니스 모델

### 2.1 서비스 개요

핀태그는 **"CFO가 없는 기업을 위한 AI 금융 비서"**를 표방하는 B2B SaaS 플랫폼입니다.

**핵심 가치 제안**: "분산된 자산을 하나로" - 복잡한 기업 금융을 단순화하고, 데이터 기반의 스마트한 의사결정 지원

### 2.2 주요 기능

| 기능 | 설명 |
|------|------|
| **통합 자산 관리** | 은행, 보험, 리스, 증권 등 분산된 금융자산을 한 대시보드에서 통합 |
| **AI 기반 분석** | AWS & Vector DB를 활용한 실시간 자산 분석 |
| **자동 알림 시스템** | 만기일 자동 알림 (카톡, 이메일, SMS, 기업 메신저) |
| **맞춤형 리포트** | 부서별·담당자별 자유도 높은 보고서 생성 |
| **견적 취합** | 자산 재계약 시 전문가 견적서 자동 취합 |
| **메신저 통합** | Slack, 잔디 등 자연어 기반 대화형 분석 |

### 2.3 지원 자산 카테고리
- 은행 계좌 (IBK, KB, 하나, 우리, 신한, 농협)
- 기업카드, 증권
- 보험 (화재, 임원, 산재, 직원)
- 리스 (차량, 정수기, 공기청정기)
- 퇴직연금, 펀드, 예금, 대출, 외화, 투자

### 2.4 요금제

| 플랜 | 가격 | 사용자 | 주요 특징 |
|------|------|--------|-----------|
| **무료 체험** | ₩0 | 10명 | 기본 기능 영구 체험, 월 100건 API, 500MB 저장 |
| **프로** | ₩100,000/월 | 50명 | 전담 지원, 월 1,000건 API, 10GB 저장, 14일 무료 체험 |
| **엔터프라이즈** | 별도 문의 | 무제한 | 맞춤형 기능, 최고 수준 보안, 온프레미스 배포 |

### 2.5 타겟 고객
- 스타트업 및 성장 기업
- 중소기업 (CFO가 없는 기업)

### 11.1 종합 평가

**주의 요소**:
