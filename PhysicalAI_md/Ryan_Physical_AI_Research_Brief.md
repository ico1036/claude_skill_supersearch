### 왜 "지금" Physical AI인가?

**3가지 기술 수렴:**

1. **LLM의 성숙** (2022-2023)
   - ChatGPT가 보여준 언어 이해 능력
   - 웹 스케일 데이터로 학습된 "상식"

2. **VLM으로의 확장** (2023-2024)
   - 이미지 + 텍스트 → 시각적 추론
   - PaLM-E가 로봇 센서 데이터와 통합 가능성 증명

3. **VLA의 탄생** (2024-2025)
   - Vision + Language + **Action**
   - 모델이 직접 로봇 관절 명령 출력

> **핵심 통찰:**
> "2023년이 세계가 생성형 AI를 발견한 해였다면, 2024년은 통합과 실험의 해였고, 2025-2026년은 AI 어시스턴트에서 Agentic AI로의 전환—질문에 답하는 것이 아니라 실제로 행동하는 자율 시스템"
> — [Innovation Mode](https://theinnovationmode.com/the-innovation-blog/2026-innovation-trends)

## 섹션 2: 기술 분해

### VLA (Vision-Language-Action) 모델이란?

```
┌─────────────────────────────────────────────────────────────────┐
│                    VLA 모델 작동 원리                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   입력                      처리                      출력      │
│   ─────                    ─────                    ─────      │
│                                                                 │
│   📷 카메라 이미지  ─┐                                          │
│                      │     ┌──────────────────┐                │
│   💬 언어 명령    ───┼────►│   VLA 모델       │────► 🤖 로봇   │
│   "컵을 싱크대에      │     │  (Transformer)   │       관절 명령│
│    옮겨줘"           │     └──────────────────┘                │
│                      │                                          │
│   🎮 로봇 상태   ────┘                                          │
│   (관절 각도 등)                                                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**핵심 정의:**
> "로봇 학습에서 VLA 모델은 비전, 언어, 행동을 통합하는 멀티모달 파운데이션 모델이다. 로봇 주변 환경의 이미지와 텍스트 명령이 주어지면, VLA는 저수준 로봇 행동을 직접 출력한다."
> — [Wikipedia](https://en.wikipedia.org/wiki/Vision-language-action_model)

### RT-2 vs PaLM-E: 핵심 차이

| 특성 | RT-2 | PaLM-E |
|------|------|--------|
| **개발사** | Google DeepMind | Google Research |
| **출시** | 2023년 7월 | 2023년 3월 |
| **파라미터** | 55B (PaLI-X 기반) | 562B |
| **목적** | 로봇 직접 제어 | 멀티모달 추론 + 계획 |
| **행동 출력** | 직접 토큰화된 행동 | 고수준 행동 계획 |
| **특징** | 웹 데이터 + 로봇 데이터 공동 학습 | 로봇 센서를 언어 토큰으로 임베딩 |

**아키텍처 비교:**

```
RT-2 아키텍처:
┌─────────────────────────────────────────────────────────────┐
│  PaLI-X / PaLM-E (백본)                                     │
│  ┌─────────┐    ┌─────────┐    ┌─────────────────────────┐ │
│  │ 이미지  │───►│ 언어    │───►│ 행동 토큰 (7차원)       │ │
│  │ 인코더  │    │ 모델    │    │ [x, y, z, rx, ry, rz, g]│ │
│  └─────────┘    └─────────┘    └─────────────────────────┘ │
│                                        │                    │
│                                        ▼                    │
│                               로봇 관절 명령               │
└─────────────────────────────────────────────────────────────┘

PaLM-E 아키텍처:
┌─────────────────────────────────────────────────────────────┐
│  540B Language Model (PaLM)                                 │
│  ┌─────────┐    ┌─────────────┐    ┌──────────────────────┐│
│  │ 센서    │───►│ 연속 임베딩 │───►│ 고수준 행동 계획     ││
│  │ 데이터  │    │ 공간 통합   │    │ "1. 찾기 2. 집기..." ││
│  └─────────┘    └─────────────┘    └──────────────────────┘│
│                                             │               │
│                                             ▼               │
│                              저수준 컨트롤러로 전달        │
└─────────────────────────────────────────────────────────────┘
```

### VLA 모델의 두 가지 접근법

| 접근법 | 대표 모델 | 장점 | 단점 |
|--------|----------|------|------|
| **이산 토큰 출력** | RT-2, OpenVLA | 구현 간단, 웹 데이터 활용 | 정밀도 한계, 느린 반응 |
| **연속 출력 (확산/플로우)** | π0, GR00T N1 | 50Hz 고주파 제어, 정밀 조작 | 복잡한 아키텍처, 훈련 어려움 |

### 왜 "단순히 LLM을 로봇에 넣으면" 안 되는가?

> "LLM은 항해에 대한 모든 책을 읽었지만 평생 뭍에서만 있던 사람과 같다. **배를 조종하는 물리적 감각이 없다.**"
> — [Scientific American](https://www.scientificamerican.com/article/why-humanoid-robots-and-embodied-ai-still-struggle-in-the-real-world/)

**핵심 문제:**
1. **체화된 지식 부재**: 텍스트 데이터만으로는 물리적 상호작용 학습 불가
2. **실시간 피드백 없음**: LLM은 정적 추론, 로봇은 동적 환경
3. **행동 공간 차이**: 텍스트 토큰 ≠ 연속적 관절 각도
4. **지연 시간**: GPT 응답 1-2초 vs 로봇 제어 10-100ms 필요

### 한계점 1: Generalization (일반화) 문제

**문제 정의:**
> "훈련 분포 내 99% 성공해도, 분포 외 상황은 무한대."

**구체적 수치:**
- ELLMER 비전 시스템: 이상적 조건에서 **100%** 정확도
- 80-90% 가려진 물체: **20%**로 급락
- 출처: [Nature Machine Intelligence, 2025](https://www.nature.com/articles/s42256-025-01005-x)

**자율주행과의 유사성:**
| 자율주행 (2015-2020) | Physical AI (2024-2025) |
|---------------------|------------------------|
| "5년 뒤면 완전 자율주행" | "몇 년 뒤면 휴머노이드 대중화" |
| Long-tail: 마지막 1%가 무한대 | Generalization gap: 훈련 외 상황이 무한대 |

### 한계점 2: 환각 (Hallucination) 위험

> "어떤 복잡하고 구조화된 데이터를 생성하려는 생성 모델도 때때로 환각을 일으킬 것이다. 더욱이 최근 AI 스케일링 법칙의 성공이 시사하는 것과 달리, 훈련 데이터의 대규모 증가조차 이런 종류의 환각을 사라지게 하지 않을 것이다."
> — [arXiv, 2025](https://arxiv.org/html/2504.08526v1)

**Physical AI에서의 환각 위험:**
- LLM이 존재하지 않는 물체를 "보았다"고 보고
- 불가능한 물리적 행동 계획
- **결과:** 로봇이 현실과 다른 행동 → 충돌, 손상, 안전 사고

**핵심 인사이트:**

>
> **구분이 중요:**
> - ✅ **반응적 적응 (Reactive)**: 컵이 움직이면 → 재조정해서 붓기 (가능)

### 상세 답변 (롱폼용)

#### 조건 (Condition): 어디서 되는가?

**현재 성공하는 환경:**
```
✅ 통제된 환경 (창고, 공장)
✅ 반복 작업 (픽앤플레이스)

✅ 단일 태스크 최적화
```

```
❌ 예측 불가 상황 (사람이 컵 옮김)
❌ 고속 정밀 작업 (20g/s 오차)
```

1. **Generalization**: 훈련 외 상황 무한대
2. **배터리**: 2-4시간 vs 필요 8시간
3. **환각**: 물리적 세계에서의 허구적 행동
